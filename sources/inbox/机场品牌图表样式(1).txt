标注：必须在图上清晰标注“原生 IP”、“防 QoS”、“专线直连”等 SEO 关键卖点。


整体视觉定位：专业网络实验室 / 网络可观测性平台，而非 VPN 营销海报。
设计语言采用 Dark Network Observatory + Infrastructure Dashboard + SaaS Monitoring Console 风格，参考 Cloudflare Dashboard、Grafana 网络监控、现代数据中心 NOC 与云基础设施控制台的视觉逻辑，但不得直接复刻任何现有产品界面。

以 深海军蓝 / 深灰蓝 为主背景，搭配低饱和描边、分层卡片、细网格、状态灯、节点标签、线路路径和高密度技术信息；每个机场仅使用少量独立 Accent Color 作为品牌识别色，避免大面积渐变和高饱和霓虹。

数值、延迟、带宽、节点状态等核心信息使用高对比度数字字体或等宽字体，重要指标允许加入轻微 Glow，但必须克制。视觉层级应优先突出：
品牌 → 测试状态 → 核心指标 → 节点区域 → 技术参数 → 数据来源。

图表内部采用明确的系统状态语言，例如：
Operational / Stable / Partial / Unavailable / Not Tested / Vendor Data / Measured Data，并通过圆点、Badge、细色条和状态色区分，而不是大量使用夸张的 ✅❌ Emoji。

测速图应像 Performance Monitoring Report；AI / 流媒体解锁图应像 Service Availability Matrix；线路拓扑图应像 Network Path Observatory；品牌概览图应像 Infrastructure Service Snapshot。

禁止设计成：传统 VPN 广告 Banner、Clash 原始截图、廉价黑绿 Hacker 风、游戏 HUD、夸张赛博朋克界面或堆满发光效果的科技海报。

最终成品应让用户第一眼感觉这是一个专业网络测试实验室生成的数据报告，而不是机场商家的宣传素材。

固定下来：

统一结构，不统一外观细节。 16 个品牌共用同一套设计系统和组件逻辑，但通过品牌 Accent Color、节点分布、协议、线路类型、套餐指标、测试结果和重点场景形成明显差异，避免 16 张图只是替换品牌名称。
